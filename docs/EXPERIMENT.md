# Native auto-translation investigation

## Hypotheses

- **H1 — UI filtering:** Android obtains target-language tracks but hides some in the picker.
- **H2 — lazy generation:** The target is not enumerated until a language choice or caption request causes YouTube to produce it.
- **H3 — backend limitation:** YouTube does not serve the requested translation for the selected video on Android.
- **H4 — add-on overlay confusion:** The translation seen after selecting a language is generated by the other add-on, not YouTube's own caption engine.

Do not assume one hypothesis is true based on the language appearing in a settings dialog.

## Controlled test (same video and app build)

1. Disable the other AI caption add-on completely and record Android's native subtitle language options.
2. Re-enable it, select a target absent from the native picker, and record whether subtitle text appears in **native YouTube caption styling** or the add-on overlay.
3. Toggle the add-on's translation engine off while retaining its saved language setting. Repeat and capture the actual caption track identity, if available.
4. Compare desktop auto-translation for the same video and language; note this is **not** proof Android supports an identical endpoint.
5. Gather sanitized logs around caption-track selection and the requested target code. Never include API keys, user sessions, auth tokens, or private video data.
6. Check language behavior after seeking, video changes, caption-off, manual selection, and Shorts.

## Relevant upstream entry points

- [Morphe PR #3566](https://github.com/MorpheApp/morphe-patches/pull/3566)
- `PreferredCaptionLanguagePatch.java`: `patch_getDirectCaptionTracks()`, `patch_getAutoTranslateCaptionTracks()`, `getPreferredCaptionTrack()`
- `PreferredCaptionLanguagePatch.kt`: caption-manager hooks and native object interfaces.

## Minimum acceptance for a working patch

- Native YouTube captions are actually translated to a target **absent** from Android's initial picker.
- The test is reproducible without relying on the original AI add-on.
- The method works for several unrelated languages/videos, not only Turkish.
- No other subtitle languages are mis-selected; caption-off and manual selection continue to work.
- No external translation requests or keys are needed.

Until this evidence exists, **do not claim to unlock all YouTube languages**.
